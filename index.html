Stem Agent

Applied AI, 2026

An LLM agent that specializes itself for a domain by evolving pipelines of typed tools, and keeps what works between sessions.

  • Every tool declares input and output types; pipelines that don't type-check can't run.
  • Six mutation operators with beam search; a MAP-Elites archive keeps the skill library diverse.
  • Runs locally on LM Studio with Gemma, with an external judge only when a key is set.

Python, LM Studio, Gemma, MAP-Elites

Refreshify 1.1

Cleans up, repairs and updates Windows with the tools Windows already has, without a terminal window.

  • Runs 16 built-in tools in an order that avoids known failures, after creating a restore point.
  • Recognizes 15 common failures and fixes the ones it safely can.
  • Turns a failed step into a report for an AI assistant, with personal paths hidden.

C#, .NET, WinUI 3, Windows App SDK

Pwrschdlr 1.0

A power scheduler, minus the vowels. Shuts down, restarts, sleeps, hibernates or signs out when a timer runs out.

  • A one-time Task Scheduler task keeps the timer when the app is closed; nothing stays running.
  • An always-on-top warning before the end lets you cancel or postpone.
  • A timer missed while the PC was off never fires late.

C#, .NET, WinUI 3, Task Scheduler, Inno Setup

Download Website Source

PermaDel 1.0

Securely shreds files and folders on Windows so recovery tools can't bring them back.

  • File Explorer context menu and an optional Windows Hello check before shredding.
  • Overwrites alternate data streams, flushes every pass to disk and refuses unsafe targets.
  • Forensic tests scan a raw disk image to prove the data is gone.

C#, .NET, WinUI 3, C++, Inno Setup

Download Website Source

PerfWindow 0.10

Real-time hardware monitor for Windows: load, temperatures, power and lifetime data for every component.

  • Rust and egui dashboard fed by a .NET sensor service built on LibreHardwareMonitor, over a named pipe.
  • The service starts on demand and exits with the window: nothing stays resident, no tray icon.
  • The installer handles the signed PawnIO driver, elevation and clean removal.

Rust, egui, C#, .NET 8, Inno Setup
