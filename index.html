An LLM agent that specializes itself for a domain by evolving pipelines of typed tools, and keeps what works between sessions.

PermaDel

Securely shreds files and folders on Windows so recovery tools can't bring them back.

  • WinUI 3 app with a File Explorer context menu and optional Windows Hello check before shredding.
  • Overwrites alternate data streams, flushes every pass to disk and refuses unsafe targets.
