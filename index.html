Pwrschdlr 1.0

A power scheduler, minus the vowels. Shuts down, restarts, sleeps, hibernates or signs out when a timer runs out.

  • A one-time Task Scheduler task keeps the timer when the app is closed; nothing stays running.
  • An always-on-top warning before the end lets you cancel or postpone.

PermaDel 1.0

Securely shreds files and folders on Windows so recovery tools can't bring them back.

  • Overwrites alternate data streams, flushes every pass to disk and refuses unsafe targets.
